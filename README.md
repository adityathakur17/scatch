# Scatch - Online Bag Store

**Scatch** is an online bag store designed with a strong emphasis on backend development. Built using **Node.js**, **Express**, and **MongoDB**, it features robust APIs for product management, user authentication, and order processing. The frontend, powered by **EJS**, provides a simple and responsive interface for browsing bags, managing carts, and placing orders.

## Key Features
- **Product Management**: Add, update, and delete products with ease.
- **User Authentication**: Secure user registration and login using JWT.
- **Order Processing**: Efficient handling of orders and payments.
- **Responsive Frontend**: Simple and intuitive interface built with EJS.

## Technologies Used
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Frontend**: EJS (Embedded JavaScript)
- **Authentication**: JWT (JSON Web Tokens)
- **Payment Integration**: Stripe or PayPal (optional)
